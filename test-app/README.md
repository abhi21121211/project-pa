# React Todo App

A simple and beautiful Todo application built with React.

## Features

- ✅ Add new todos
- ✅ Mark todos as complete
- ✅ Delete todos
- ✅ Filter by All/Active/Completed
- ✅ Beautiful gradient UI
- 🔐 Admin Dashboard (Protected Route)

## Tech Stack

- React 18
- Vanilla CSS with Gradients
- HTML5

## Getting Started

```bash
# Open in browser
open index.html
```

## Protected Routes

This app includes a protected Admin Dashboard route (`/admin`) that requires authentication to access.
